# pingipv6

Ping validation gates for ipv6 inputs before they hit prod.

**Site:** https://theworker02.github.io/pingipv6/

## Install / run

```bash
git clone https://github.com/theworker02/pingipv6.git
cd pingipv6
node src/cli.js
node --test
```
